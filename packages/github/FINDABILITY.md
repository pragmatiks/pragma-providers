# Findability audit: github

Each row records how a resource type meets the Pragmatiks findability and idempotency contract; the contract, the columns and the verdict rule are in `## Findability audit` of the repository's `CLAUDE.md`. Audited 2026-11-02 against `main@8754f36`; vendor documentation read 2026-11-02.

| Type | Identity | `on_observe` lookup | Uniqueness | Findable from send | Conflict on create | Partial create | Rerun | Verdict | Evidence |
|---|---|---|---|---|---|---|---|---|---|
| `github/repository` | `owner` (path of `POST /orgs/{org}/repos`, or the token user for `POST /user/repos`), `name` (both `ImmutableField`) | `Repository.on_observe` → `GET /repos/{owner}/{name}`; a redirect (renamed or transferred) counts as absent | Yes: a taken name is refused 422 with a `name` error `already_exists` (`is_name_taken`); the docs list 422 "Validation failed" | unknown: the docs say nothing on reading a repository right after its create | Raises `AlreadyExistsError`. No marker fits: the create body's free fields (`description`, `homepage`) are user configuration, topics are not accepted at create, and `custom_properties` exists only on the organization endpoint and only for properties the organization defined | One write (`auto_init` is part of it) | `on_update` patches every mutable setting; `on_delete` treats 404 and a redirect as deleted | gap (PRA-869) | `Repository.on_create`, `is_name_taken`, `client.fetch_optional_json`; https://docs.github.com/en/rest/repos/repos?apiVersion=2022-11-28#create-an-organization-repository |
| `github/environment` | `owner`, `repository`, `environment_name` (all `ImmutableField`), the path of `PUT /repos/{owner}/{repo}/environments/{name}` | `Environment.on_observe` → `GET` of the same path | Yes: the name is the address; the PUT is "Create or update", so a second create replaces, never duplicates | unknown: the docs say nothing on read-after-write | Raises: `client.ensure_absent` refuses an environment that exists before the PUT, because the PUT would take it over; the body has no field that can carry a marker (`wait_timer`, `prevent_self_review`, `reviewers`, `deployment_branch_policy`) | One write | `on_update` reapplies the PUT; `on_delete` treats 404 as deleted | gap (PRA-870) | `Environment.on_create`, `client.ensure_absent`; https://docs.github.com/en/rest/deployments/environments?apiVersion=2022-11-28#create-or-update-an-environment |
| `github/secret` | `owner`, `repository`, `secret_name`, `environment_name` (all `ImmutableField`), the path of the secret PUT | `Secret.on_observe` → `GET` of the secret's metadata | Yes: the name is the address; the PUT answers 201 on create and 204 on update | unknown, as environment | Raises: `client.ensure_absent`, as environment; the body is only `encrypted_value` and `key_id` | Public key read, then one write | `on_update` reapplies the PUT; `on_delete` treats 404 as deleted | gap (PRA-871) | `Secret.on_create`, `client.ensure_absent`; https://docs.github.com/en/rest/actions/secrets?apiVersion=2022-11-28#create-or-update-a-repository-secret |
