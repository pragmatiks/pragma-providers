# Findability audit: qdrant

Each row records how a resource type meets the Pragmatiks findability and idempotency contract; the contract, the columns and the verdict rule are in `## Findability audit` of the repository's `CLAUDE.md`. Audited 2026-11-02 against `main@8754f36`, and the `qdrant/collection` observe refusal 2026-11-06 against `main@bc294e3`; vendor documentation read 2026-11-02.

The resource marker is the collection metadata key `pragma_resource` holding the canonical resource ID (`marker.RESOURCE_MARKER_KEY`), the key every provider uses; collection metadata is arbitrary JSON, so no vendor rule forces another spelling.
