# Findability audit: vercel

Each row records how a resource type meets the Pragmatiks findability and idempotency contract; the contract, the columns and the verdict rule are in `## Findability audit` of the repository's `CLAUDE.md`. Audited 2026-11-23 against `main@f35a149`; vendor documentation read 2026-11-23 (reference pages and https://vercel.com/openapi.json).

A deployment a `vercel/project` triggers carries the resource marker in `meta.pragma_resource`, under the key every provider uses, and the digest of its inputs in `meta.pragma_spec`. Deployments without the marker, such as the builds Vercel starts for a Git push, are never read, written or refused. The project and domain creates still have no field that can carry the marker.
